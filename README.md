HR-AGENT

An AI-powered HR assistant that answers employee policy questions using company handbooks and helps schedule 1-on-1 performance review sessions.

Architecture

- Frontend: React.js, Vite
- Backend: Python, FastAPI
- AI & RAG: Retrieves relevant handbook content for context-aware responses with source citations.
- Workflow Orchestration: Routes requests between FAQ retrieval, conversational chat, and appointment booking.
- REST API: Connects frontend and backend while maintaining conversation context through thread IDs.

Key Features

- Retrieval-Augmented Generation (RAG) for handbook Q&A.
- Source-cited AI responses.
- Conversational appointment scheduling.
- Context-aware chat sessions and structured booking workflows.
